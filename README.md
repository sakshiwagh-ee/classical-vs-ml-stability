# Comparative Analysis of Classical Stability Criteria vs. Machine Learning-Based Stability Prediction for Second-Order Closed-Loop Control Systems

## Overview

This project presents a comparative analysis of classical stability criteria and machine learning-based stability prediction for second-order closed-loop control systems. Classical control theory is used to assess system stability, while machine learning models are evaluated for their ability to predict stable and unstable system behaviour.

MATLAB is used for classical stability analysis, and Python is used for machine learning implementation and evaluation.

## Objectives

- Analyze second-order closed-loop control system stability using classical methods.
- Implement machine learning models for stability prediction.
- Compare classical stability assessments with machine learning predictions.
- Evaluate model performance using classification metrics.
- Investigate the potential and limitations of machine learning in control-system stability analysis.

## Methodology

### 1. Classical Stability Analysis — MATLAB

Classical control-system analysis includes:

- Routh–Hurwitz stability criterion
- Bode plot and stability margins
- Nyquist plot
- Closed-loop step response
- Sensitivity and complementary sensitivity functions

These techniques are used to examine system stability and performance in the time and frequency domains.

### 2. Machine Learning-Based Stability Prediction — Python

The machine learning experiment uses a synthetically generated dataset containing system parameters and noisy measurements.

The following models are evaluated:

- Logistic Regression
- Decision Tree
- Random Forest
- Support Vector Machine (SVM)
- Multilayer Perceptron (MLP)

Model performance is assessed using accuracy, balanced accuracy, F1-score, ROC-AUC, and cross-validation, where applicable.

| Gain margin                      |   Infinite |
| Phase margin                     |      34.7° |
| Phase-margin crossover frequency | 8.13 rad/s |
| Unified Stability Index (USI)    |      0.931 |

The Routh–Hurwitz assessment indicates a stable closed-loop system for the tested configuration. The gain margin is reported as infinite because no finite phase-crossover frequency was found.

The USI is a project-defined metric combining normalized stability-related components. It is not a standardized stability measure and requires further validation.

## How to Run

### MATLAB

Open MATLAB and run:

```matlab
ClassicalStabilityPredictionDemo
```

MATLAB and the Control System Toolbox may be required, depending on the functions used in the script.

### Python

Install the dependencies listed in `requirements.txt`:

```bash
pip install -r requirements.txt
```

Run the analysis:

```bash
python stability_analysis.py
```

Ensure that the filenames and folder paths match the files uploaded to the repository.

## Limitations

- The machine learning experiment uses synthetic data.
- The results do not establish performance on real-world control systems.
- High classification accuracy alone does not demonstrate that machine learning is superior to classical stability criteria.
- Further validation is needed before applying the approach to practical control systems.
